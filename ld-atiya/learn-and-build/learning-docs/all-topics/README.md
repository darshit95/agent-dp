# All Topics - Deep Learning Repository

This folder contains comprehensive learning documents for each AI/agentic concept you master.

## Structure

Each concept gets two files:

1. **`[concept-name].md`** - Complete learning document
   - Everything you learned through conversation and Q&A
   - Detailed explanations, examples, code
   - How it fits in Atiya (when relevant)
   - All important details for mastery

2. **`[concept-name]-slides.md`** - Revision slides
   - Visual diagrams and flow charts
   - All important concepts and key points
   - Quick revision material
   - As many slides as needed to cover the material

## How It Works

When you use `/learn-and-implement [concept]`, the skill will:
1. Teach you the concept through conversation
2. Answer all your questions in depth
3. Create a comprehensive learning document capturing everything
4. Generate revision slides with all important points

## Example

```bash
/learn-and-implement Prompt Caching
```

Creates:
- `all-topics/prompt-caching.md` - Full learning document
- `all-topics/prompt-caching-slides.md` - Revision slides
